# WalletVerse

The Wallet of the Slid Phi machine: value in and out for agents —
any chain, any token, metered to the unit. If the money doesn't
verify, the wallet refuses.

| Part | Path | What it is |
|---|---|---|
| awlpay | `awlpay/` | Any chain, any token with verifiable value. Anything-to-anything conversion, or refuse. |
| agenTill | `agenTill/` | Turn any online product into a storefront AI agents can buy from — payment built in. |
| alexa-pay-mcp | `alexa-pay-mcp/` | An Alexa+ agent's wallet: self-hosted MCP server for x402 payments. |
| computepay | `computepay/` | AI & agent usage billing: meter tokens/API/GPU, attribute cost, Stripe, dashboard. |

## Provenance

Fused from four repos with full history preserved (merge commits, not
squashes), all from `main`.
